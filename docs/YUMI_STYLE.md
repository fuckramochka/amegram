# YUMI STYLE — дизайн-система Yumigram

Єдиний візуальний словник усього клієнта. Будь-який новий екран збирається
з цеглин `YumiTheme` (токени) + `YumiComponents` (фабрика), жодних
магічних dp/кольорів у коді екранів.

## 1. Принципи

1. Чисті тональні поверхні, мінімум градієнтів. Градієнт — тільки бренд
   (`LOGO_GRADIENT_START → END`) і тільки в банерах/featured.
2. Текст в колонку: заголовок → підзаголовок, без накладень.
3. Жодних хардкод-стилів: радіуси, паддинги, кегль — з `YumiTheme`.
4. Світла і темна тема працюють через ті самі токени — перевіряти обидві.

## 2. Токени (`YumiTheme`)

| Група | Токени |
|---|---|
| Радіуси | `RADIUS_SM=8` (чипи, бейджі) · `RADIUS_MD=12` (іконки, поля) · `RADIUS_LG=20` (картки) · `RADIUS_XL=28` (шити) |
| Відступи | `SPACE_XS=4` · `SPACE_SM=8` · `SPACE_MD=12` · `SPACE_LG=16` · `SPACE_XL=24` |
| Кегль | 22 display · 17 title · 15 head · 14 body · 13 small · 12 caption · 11 micro |
| Картка | поля 14/5, паддинги 16/14 |
| Кнопки | primary радіус 14 · pill/chip радіус 12/99 |

Кольори: `getPrimary()`, `getSurface*()`, `getOnSurface*()`, `getError()`,
`getLink()` — самі перемикаються під тему. Сирі hex в екранах заборонені
(виняток — білий текст на бренд-заливці).

## 3. Компоненти (`YumiComponents`)

| Компонент | Фабрика | Анатомія |
|---|---|---|
| Картка | `card()` + `cardWrap()` | surfaceContainer, 20dp, 16/14, поля списку 14/5 |
| Кнопка | `primaryButton()` | primary, білий 15, 14dp, паддинг 13 |
| Пігулка | `pillButton()` | primary, білий 13.5, 12dp, 18/9 |
| Привид | `ghostButton()` | контур, 13, 12dp, паддинг 10 |
| Чип | `chip(selected)` | 99dp, 14/8, жирний 12.5 |
| Бейдж | `badge()` | контур, 11, 8/3 |
| Баннер | `banner(title, sub)` | бренд-градієнт, 18dp, білий 16/13 |
| Шапка секції | `sectionTitle`/`sectionHeader()` | капс, акцент, 11.5 |
| Іконка | `squircleIcon(res, color, box, icon)` | сквиркл 12dp + біла іконка |
| Шит | `grabHandle()` + `sheetBackground()` | ручка 40×4, верхні кути 28 |
| Пошук | `searchField(hint)` | тональне поле, 12dp, 14/11 |
| Настройка | `YumiSettingCell.Factory.of()` | іконка 40 + колонка + шеврон/значення |

## 5. Чеклист нового екрана

- [ ] Тільки токени/фабрика, нуль hex і голих dp
- [ ] Темна + світла тема
- [ ] Тап по картці → деталка, кнопка не перехоплює тап картки
- [ ] Порожні стани (все встановлено / нічого не знайдено)
- [ ] Помилки — тостом з причиною, ніколи мовчки
