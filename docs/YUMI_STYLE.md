# YUMI STYLE — дизайн-система Yumigram

Єдиний візуальний словник клієнта. Нові екрани збираються з токенів
`YumiMd3` (`app.amegram.theme`) та компонентів `YumiSettingsView`,
`YumiBackgroundView` і `YumiSwitch`. Стара пара `YumiTheme` +
`YumiComponents` лишається для вже існуючих екранів, але новий дизайн
будується тільки на Material 3 Expressive.

## 1. Принципи

1. **Нативний Android, не iOS.** Лівий заголовок top app bar, Material-іконки,
   тональні контейнери, ripple і зрозумілі стани натискання. Жодних
   центрованих заголовків, «скляних» панелей на весь екран і iOS-перемикачів.
2. **Спокійна основа, виразні акценти.** Фон майже нейтральний; колір
   з'являється в hero-карті, іконках, перемикачах і головній дії.
3. **Одна композиція — одна думка.** Hero → пошук → швидкі дії → групи
   налаштувань → дії внизу. Секції не змагаються за увагу.
4. **Тема — це токени.** Світла й темна теми відрізняються лише значеннями
   `YumiMd3`; геометрія та ієрархія не змінюються.
5. **Кожен дотик має відповідь.** Ripple, легкий spring-масштаб, haptic,
   анімований switch. Але без нескінченних декоративних анімацій.

## 2. Токени (`YumiMd3`)

| Група | API |
|---|---|
| Поверхні | `surface()`, `surfaceContainerLow()`, `surfaceContainer()`, `surfaceContainerHigh()`, `surfaceContainerHighest()` |
| Текст | `onSurface()`, `onSurfaceVariant()`, `muted()` |
| Контури | `outline()`, `outlineStrong()`, `hairline()` |
| Бренд | `primary()`, `primaryContainer()`, `gradientStart()`, `gradientEnd()`, `actionGradientStart()`, `actionGradientEnd()` |
| Акценти | `violet()`, `cyan()`, `amber()`, `green()`, `blue()`, `orange()`, `teal()`, `neutral()` |
| Стани | `success()`, `warning()`, `error()` |
| Типографіка | `REGULAR/MEDIUM/BOLD`, `DISPLAY/HEADLINE/TITLE/TITLE_SMALL/BODY/BODY_SMALL/LABEL/CAPTION`, `typeface()`, `text()` |
| Форми | `rounded()`, `gradient()`, `ripple()`, `transparentRipple()` |
| Похідні | `tone()`, `iconTone()`, `withAlpha()`, `blend()`, `dp()` |

Правила:

- Іконки — Material Symbols Rounded у `res/drawable/yumi_ic_*.xml`, 24dp
  vector, тонуються через `ColorFilter`. Напрямні (стрілки, шеврон) мають
  `android:autoMirrored="true"`.
- Сирі hex допустимі лише для білого тексту/іконок на бренд-градієнті та
  для внутрішніх шарів hero. Усе інше — через токени.
- `tone(accent, t)` — заливка під іконку/чип; `iconTone()` автоматично
  підсилює тон у темній темі.
- Радіуси: 9–13 — дрібні чипи й іконки, 18–22 — кнопки, 24–28 — картки,
  99 — пігулки.
- Мінімальна ціль дотику — 48dp, навіть якщо візуальний елемент менший.

## 3. Фон і сітка

`YumiBackgroundView` малює:

- базовий `surface()`;
- три статичні радіальні свічення (pink / violet / cyan) з дуже низькою
  альфою;
- дві тонкі орбітальні лінії;
- ледь помітне зерно (детермінований bitmap, без анімації);
- нижнє затухання до поверхні.

Контент центрується в колонці **620dp**. На планшетах бічні поля
розраховує `YumiSettingsView`, а top app bar отримує ті самі відступи, щоб
заголовок і кнопки не «пливли» до країв екрана.

Висота top app bar — `60dp + statusBar`. Контент прокручується під нього,
панель проявляється після ~28dp скролу. Знизу — `28dp + navigationBarHeight`.

## 4. Анатомія екрана налаштувань

```
[ ← ]  Заголовок сторінки                          [ 🔍 ]   top app bar
┌─────────────────────────────────────────────────────────┐
│ YUMIGRAM · EXPRESSIVE                          [MD3]     │
│ Твоя Юмі                                                 │
│ Модулі, клієнт і стиль — усе в одному місці.             │
│ [3 активні] [v12.12.1] [Приватність]                     │  hero
└─────────────────────────────────────────────────────────┘
[ 🔍 Пошук налаштувань                                  × ]  search
Швидке керування
[ tile ] [ tile ]                                           2×2 quick tiles
[ tile ] [ tile ]
Модулі та розширення
┌─────────────────────────────────────────────────────────┐
│ [icon] Ghost mode                              [switch] │
│ [icon] Cloud vault                             [switch] │
└─────────────────────────────────────────────────────────┘
...
[ Налаштувати клієнт ] [ Каталог ]                          footer actions
              Юмі · v12.12.1 · модульний клієнт
```

- **Hero** — єдина темна брендова поверхня на світлій темі. Радіус 28dp,
  внутрішній градієнт violet → wine, два м'які свічення, тонкі орбіти,
  лого 64dp. На екранах 320dp бейдж `MD3` ховається, щоб не краяти заголовок.
- **Search** — тональна пігулка 56dp із провідною іконкою, полем і кнопкою
  очищення 48dp. Фокус підсвічує контур `primary` і відкриває клавіатуру.
- **Quick tile** — картка 2×2 з акцентним тонуванням, іконкою 38dp,
  заголовком, двома рядками опису і switch/chevron. Висота ≥136dp.
- **Group card** — одна тональна картка на секцію, рядки 68dp, роздільники
  з відступом під текст. Перший і останній рядок мають радіус картки.
- **Switch** — `YumiSwitch`: трек 52×32, білий thumb, галочка, spring
  overshoot, haptic. Колір приймає від рядка, тому працює на будь-якому тоні.
- **Footer actions** — головна дія на градієнті `actionGradientStart → actionGradientEnd`
  (AA-контраст із білим підписом), другорядна — тональна. Висота 52dp, радіус 18dp.
- **Empty state** — іконка, заголовок, запит у тексті, кнопка скидання.

## 5. Модель і пошук

`YumiSettingsModel` — єдине джерело даних для екрана. Активність не малює
View-и, а лише описує `Hero`, `Quick`, `Section`, `Row`, `Action`.
`YumiSettingsView` рендерить модель і повідомляє слухача про події.

Пошук:

- індексує заголовок, підпис, значення та `moduleId` кожного рядка;
- шукає також у прихованих рядках сторінки клієнта (`model.searchIndex`);
- ігнорує регістр і зайві пробіли;
- не дублює quick-рядок і такий самий рядок секції;
- під час фільтрації зберігає фокус у полі (оновлюється тільки хвіст списку);
- показує кількість збігів з правильним відмінком через `MiogramLocale.plural`;
- порожній стан цитує запит і дає кнопку «Скинути пошук».

## 6. Локалізація

Усі рядки — через `MiogramLocale.get(uk, ru, en)` або `.format(...)`.
Числівники — тільки через `MiogramLocale.plural(...)`: він знає українські,
російські та англійські форми (1 активний / 2 активні / 5 активних).
Не складайте числа й іменники конкатенацією вручну.

## 7. Рух

| Подія | Рух |
|---|---|
| Перший показ | fade + 14dp підйом, stagger 35ms для перших 7 елементів |
| Натискання картки/кнопки | scale 0.975, 110ms; повернення 150ms |
| Switch | 280ms spring, overshoot ~1.12 |
| Пошук | debounce 90ms, список оновлюється без перебудови поля |
| Top bar | проявлення 0→1 за перші 28dp скролу |

Анімації не мають блокувати скрол і не повторюються під час звичайного
`refresh()`.

## 8. Чеклист нового екрана

- [ ] Композиція з `YumiMd3`, без XML-лейаутів і сирих dp/hex
- [ ] Світла + темна тема, обидві перевірені на реальному пристрої
- [ ] Телефон 320/360dp і планшет ≥620dp
- [ ] Цілі дотику ≥48dp, contentDescription у кнопок і перемикачів
- [ ] RTL: `setMarginStart/End`, autoMirrored іконки стрілок
- [ ] Порожній стан, стан помилки, довгі рядки (2 рядки + ellipsis)
- [ ] Пошук знаходить приховані пункти й не дублює результати
- [ ] Усі маршрути ведуть туди ж, куди до редизайну

## 9. Legacy

`YumiTheme` / `YumiComponents` лишаються для старих екранів
(HotStoreActivity, HotModulesActivity, лего-шити модулів тощо). Їхні
правила — тональні картки, фабрики `card()`, `primaryButton()`, `chip()`,
`banner()` — не застосовуються до нових екранів. Поступово мігруйте їх на
`YumiMd3`.
