# Amegram Hot Modules

Репозиторій нативних модулів розширення для **Amegram** на базі офіційного клієнта Telegram.
Модулі завантажуються динамічно у процес без перезапуску застосунку, мають нульове навантаження у вимкненому стані та підтримують версіонування й відкат.

## Список модулів у репозиторії

| Модуль | Назва | Опис | Головний клас |
|---|---|---|---|

| `ghost` | **Режим привида** | Повна невидимість: блокування readHistory, readStories, typing та підміна online на offline. | `com.amegram.mods.ghost.GhostModule` |

| `vault` | **Хмарне сховище** | Зашифрований AES-256-GCM віртуальний диск у форум-супергрупі з нарізанням файлів на чанки по 100 МБ та автосинхронізацією. | `com.amegram.mods.vault.VaultModule` |
| `tiktok` | **TikTok MI** | Вбудований відеоплеєр без водяних знаків, очищення трекінг-посилань та синхронізація акаунта TikTok MI. | `com.amegram.mods.tiktok.TikModule` |

| `experimental` | **Експерименти** | Безліміт закріплених чатів та стікерів, прискорення завантаження, шумозаглушення, підвищений бітрейт відео, збереження видалених. | `com.amegram.mods.experimental.ExperimentalModule` |

| `demo` | **Демо модуль** | Шаблон мінімального модуля для сторонніх розробників. | `com.amegram.mods.demo.DemoModule` |

## Як це працює ("і то і то працює")

1. **Із коробки (Bundled Fallback)**:
   Всі модулі постачаються у `assets/hotmodules/`. При першому запуску клієнт автоматично розгортає їх на диск, тому клієнт працює повністю автономно навіть без доступу до інтернету.
2. **Динамічні оновлення (GitHub OTA)**:
   При публікації нових релізів на GitHub застосунок перевіряє `modules.json` через `HotConfig.CATALOG_URL`, пропонує оновлення у розділі *Amegram → Хот-модулі → Каталог* і завантажує оновлені `.hmod` пакети.
3. **Безпека та відкат**:
   При вимкненні модуля активується 100% стокова логіка офіційного Telegram. Якщо модуль збійнув або не завантажився — система автоматично вимикає його без падіння додатку.

## Збірка та публікація

```bash
# Спакувати всі модулі та оновити sha256 у modules.json:
python3 package_all.py

# Або зібрати окремий модуль за наявності Android SDK:
./build.sh player 1.0.0 stable
```

Створені файли в папці `out/*.hmod` завантажуються у відповідний GitHub Release (наприклад, `player-1.0.0`), після чого `modules.json` пушиться у гілку `main`.
